# Dashboard automático dos relatórios

Foram analisadas todas as seis folhas de `Relatorio Mensal.xlsx`, incluindo os dados fora do bloco inicial e o gráfico da folha Dashboard. O ficheiro orienta a estrutura, sem importar os seus valores históricos para períodos atuais.

| Folha | Aplicação no dashboard |
| --- | --- |
| Relatorio de Viaturas | Entradas/saídas por dimensão ou regime, último saldo observado de viaturas em parque e métricas de apreensão. Matrículas e autos continuam nos anexos. |
| Selos Usados No Armazem | Indicador estruturado Selos utilizados, por portão/dimensão. Números de série dos selos nunca são somados. Tabelas configuradas apresentam contagem de linhas, identificada como tal. |
| Informacao Geral | Contagens de ocorrências estruturadas, pendências e atividade nas tabelas. Texto narrativo não é interpretado como uma quantidade validada. |
| Iluminacao | Combustível por equipamento, duração dos cortes e evolução das leituras. Leituras acumuladas não equivalem a consumo. |
| Resumo | Indicadores, cobertura das fontes, distribuição por dimensão e comparação com o período anterior. |
| Dashboard | Painel de abertura com identidade GT, gráficos visíveis automaticamente e incorporados no PDF e Word. |

Os indicadores já disponíveis de manutenção, suporte IT e CCTV são apresentados conforme os dados guardados na consolidação. Uma dimensão Geral não é somada automaticamente às dimensões detalhadas. Ausência de observação não se transforma em zero. Divergências excluídas pela consolidação permanecem excluídas dos gráficos.

Os dashboards são derivados do snapshot guardado da versão. Novos documentos oficiais incorporam os gráficos. PDFs e Word oficiais já arquivados não são reescritos; uma nova cópia/versão permite obter a apresentação atualizada.
